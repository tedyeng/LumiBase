## 1. 介面導覽 (Interface Layout)

LumiBase 採用專業深色工作介面，分為三大核心區塊：

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│  [Open Folder] [Export]                    Top Toolbar                     [F7] [F8]   │
├─────────────────┬──────────────────────────────────────────────────────┬───────────────┤
│                 │  Top Filter Bar: 🔍 Search (⌘F) | Rating | Flag     │  Histogram    │
│  LEFT SIDEBAR   ├──────────────────────────────────────────────────────┤  [Edit][Crop] │
│  (F7 / Tab)     │                                                      ├───────────────┤
│                 │  CENTER WORKSPACE                                    │  DEVELOP      │
│  - Recent Folders│                                                      │  BASIC PANEL  │
│  - Places & Disks│  - Grid View (網格總覽, G)                            │  - WB         │
│  - Smart Search │  - Loupe View (大圖 120fps 預覽, E / Space)          │  - Tone       │
│                 │                                                      │  - Presence   │
│                 ├──────────────────────────────────────────────────────┤  - Metadata   │
│                 │  Filmstrip View (底部底片縮圖列)                      │  [Sync][Copy] │
└─────────────────┴──────────────────────────────────────────────────────┴───────────────┘
```

- **左側導覽列 (Left Sidebar)**：資料夾樹狀目錄、最近開啟紀錄（Recent Folders）、磁碟槽與外接硬碟。
- **中央工作區 (Center Workspace)**：網格檢視（Grid）、大圖檢視（Loupe）與底部底片列（Filmstrip）。
- **右側檢查器 (Right Inspector)**：即時色階分佈圖（Histogram）、Develop Basic 調色面板、Crop 裁切面板與 EXIF/XMP 中繼資料編輯。

> 💡 **小技巧**：隨時按下 **`Tab`** 鍵可一鍵同時收合或展開左右兩側面板，最大化預覽視野。

## 2. 相片載入與目錄管理 (Folder Management)

### 開啟目錄
- 點擊工具列上的 **「Open Folder」** 按鈕或按下 **`⌘O`** (Command + O) 選擇相片目錄。
- **無限制樹狀總管 (Folder Tree)**：在左側面板可直接點開本機硬碟與外接裝置（如 `/Volumes/Extreme SSD`），層層點開目錄瀏覽。
- **最近開啟紀錄 (Recent Folders)**：系統會自動記錄最近點選的 5 個相片資料夾並置頂於左側最上方，方便一鍵快速跳轉。

## 3. 高速選圖與評級篩選 (Culling & Filtering Workflow)

### 3.1 網格導覽與檢視切換
- **上一張 / 下一張**：按下 **`←`** / **`→`** 方向鍵。
- **網格 2D 跳行**：在 Grid View 下按下 **`↑`** / **`↓`** 方向鍵可依目前欄數整行跳轉。
- **大圖預覽 (Loupe View)**：選取相片後按下 **`Enter`**、**`Return`**、**`E`** 或 **`Space`**（空白鍵）進入大圖。
- **返回圖庫網格 (Grid View)**：按下 **`Esc`** 或 **`G`** 鍵。
- **100% 畫素檢視 (Zoom 1:1)**：在大圖預覽下按下 **`Z`** 鍵或雙擊滑鼠，即可在「Fit 全圖適配」與「100% 原生畫素」間切換。

### 3.2 星等評分與旗標標記 (Rating & Flagging)
- **星等評分 (0 ~ 5 星)**：
  - 按下數字鍵 **`0`**、**`1`**、**`2`**、**`3`**、**`4`**、**`5`** 直接設定。
  - 按下 **`]`** 鍵增加一星，按下 **`[`** 鍵減少一星。
- **旗標標記 (Flags)**：
  - **`P`**：標記為留用（Pick Flag，白色旗標）。
  - **`X`**：標記為剔除（Reject Flag，紅色打叉）。
  - **`U`**：取消標記（Unflagged）。

### 3.3 頂部快速篩選 (Top Filter Bar)
- **關鍵字搜尋 (`⌘F`)**：按下 **`⌘F`** 聚焦搜尋框，可即時過濾檔名、相機型號或關鍵字。按 **`Esc`** 可一鍵退出搜尋焦點。
- **星等篩選**：點擊頂部 $\ge 1\text{★} \sim 5\text{★}$，即時過濾高評分相片。
- **旗標篩選**：一鍵查看 Pick、Reject 或未標記相片。

## 4. 基礎調光與色彩調整 (Develop Basic Adjustments)

LumiBase 內建 100% 忠實還原 Adobe Camera RAW (PV2012) 標準的 GPU 即時調色管線：

### 4.1 白平衡 (White Balance)
- **色溫 (Temp)**：$2000\text{K} \sim 50000\text{K}$。
- **色調 (Tint)**：$-150 \sim +150$（洋紅／綠色微調）。
- **WB 預設選單**：支援 As Shot（機身原始）、Auto、Daylight、Cloudy、Shade、Tungsten、Fluorescent、Flash、Custom。

### 4.2 處理模式 (Treatment)
- 點擊頂部 **Color** 或 **Black & White** 按鈕，切換彩色與黑白模式。黑白模式下自動聯動標準灰階演算法。

### 4.3 基礎色調 (Tone)
- **曝光度 (Exposure)**：$-5.00 \sim +5.00\text{ EV}$ 線性光子曝光增益。
- **對比度 (Contrast)**：$-100 \sim +100$ 中灰度 S 曲線微調。
- **高光 (Highlights)**：$-100 \sim +100$ 非線性高光壓制，挽救過曝細節。
- **陰影 (Shadows)**：$-100 \sim +100$ 暗部細節提亮與加深。
- **白色端點 (Whites)**：$-100 \sim +100$ 動態範圍白點極限校正。
- **黑色端點 (Blacks)**：$-100 \sim +100$ 動態範圍黑點極限校正。
- **自動色調 (Auto Tone)**：點擊 `Auto` 按鈕，系統將自動平衡曝光與高光陰影分佈。

### 4.4 外觀質感 (Presence)
- **紋理 (Texture)**：微距毛髮細節銳化（正值）或人像膚質自然柔化（負值）。
- **清晰度 (Clarity)**：中頻對比強化（正值）或夢幻柔焦（負值）。
- **去朦朧 (Dehaze)**：消除大氣水氣霧霾（正值）或營造朦朧晨霧感（負值）。
- **鮮豔度 (Vibrance)**：人像膚色保護型飽和度提亮。
- **飽和度 (Saturation)**：全域線性色彩飽和度調整。

### 4.5 專業滑桿互動技巧
- **雙擊復位**：雙擊滑桿標題文字或軌道，立即將該數值復位為預設值。
- **鍵盤數字精確輸入**：點擊數值標籤（如 `+0.20`），直接鍵入數字後按 `Enter` 套用。
- **Tab 連續跳轉**：在數值輸入狀態下，按 **`Tab`** 跳至下一個滑桿輸入框，按 **`Shift+Tab`** 跳回上一個輸入框。

## 5. 裁切與水平旋轉校正 (Crop & Straighten Tool)

LumiBase 提供 1:1 媲美 Lightroom Classic 的互動裁切與水平校正系統：

### 5.1 進入與退出裁切
- **進入裁切模式**：按下快捷鍵 **`R`**，或點擊右側檢查器標頭的 **Crop 圖示**（`crop`）。
- **確認並套用**：按下 **`Enter`**、**`Return`**、再次按 **`R`**，或點擊右側面板金色 **「Done」** 按鈕。
- **取消並退出**：按下 **`Esc`** 鍵放棄本次調整。
- **復位裁切**：點擊右側面板的 **「Reset Crop」** 按鈕。

### 5.2 裁切操作與手勢
- **8 個控制錨點**：拖曳 4 個角落或 4 條邊框的手柄，自由縮放裁切範圍。
- **平移視角 (Pan)**：在裁切框內部按住滑鼠拖曳，即可移動畫面構圖。
- **長寬比例鎖定 (Aspect Ratio)**：
  - 支援選單預設：`Original`（相機原尺寸）、`1:1`（正方形）、`4:5 (8x10)`、`5:7`、`16:9`、`Custom`（自訂自由比例）。
  - 點擊鎖頭圖示（`Locked` / `Unlocked`）可自由鎖定或解除比例限制。
- **直橫向快速翻轉 (`X` 鍵)**：按下鍵盤 **`X`** 鍵，瞬間將裁切框在橫向（Landscape）與直向（Portrait）之間對調。

### 5.3 視窗自適應輔助格線與切換 (`O` 鍵)
- **多線對齊格線 (Alignment Grid)**：根據視窗大小自動計算密集細緻的水平與垂直格線（每 32pt 一格，全螢幕下約 25～35 條），極方便精確對齊地平線與建築線條。
- **三分九宮格 (Rule of Thirds)**：經典 $3 \times 3$ 黃金比例構圖線。
- **切換模式 (`O` 鍵)**：按下鍵盤 **`O`** 鍵或點擊面板的 **「Tool Overlay」** 按鈕，即可在對齊格線與三分法則間即時切換。

### 5.4 水平旋轉校正 (Straighten)
- **角度滑桿 (Angle)**：提供 $-45.0^\circ \sim +45.0^\circ$ 旋轉調整。
- **120 FPS GPU 直驅預覽**：Apple Silicon Metal 硬體直驅旋轉，滑動滑桿全程無延遲、零掉幀。

## 6. 批次同步與自動同步 (Develop Sync & Auto Sync)

在處理成百上千張相片時，LumiBase 具備 Lightroom 等級的強大批次處理能力：

### 6.1 選擇性同步 (Sync Settings Dialog)
1. 在 Grid 或 Filmstrip 中選取多張相片（先點選已修好的**來源照片**，再按住 `⌘` 或 `Shift` 加選其他目標照片）。
2. 按下 **`⌘⇧S`** (Command + Shift + S) 或點擊右下角 **「Sync」** 按鈕。
3. 在彈出的專業對話框中選擇欲同步的項目（白平衡、色調、Presence、幾何裁切等），並可使用 `Modified Only` 快速選取已調整項。
4. 點擊 **「Synchronize」** 即刻完成批次同步。

### 6.2 即時自動同步 (Auto Sync)
1. 選取多張相片。
2. 切換右下角開關或按下 **`⌥⌘⇧S`** / **`⌥⌘S`** 啟用 **Auto Sync**（按鈕呈現金色高亮狀態）。
3. 此時在右側面板調整任何滑桿、點擊 Auto Tone 或裁切，所有選取的照片將**即時同步聯動**。

### 6.3 複製與貼上修圖設定 (Copy & Paste)
- **複製設定 (`⌘⇧C`)**：選取來源照片後按 **`⌘⇧C`**，選擇要複製的參數存入剪貼簿。
- **貼上設定 (`⌘⇧V` 或 `⌥⌘V`)**：選取一張或多張目標照片，按 **`⌘⇧V`** 快速套用。

## 7. 非破壞性 XMP 檔案機制 (XMP Sidecar Compatibility)

- **100% 非破壞性編輯**：LumiBase 永遠不會直接修改您的 RAW 原始檔案。
- **自動生成 `.xmp` 側邊檔**：當您為相片設定星等、旗標、裁切或調整色調時，系統會在相片同目錄下自動產生標準 Adobe 格式的 `.xmp` 副檔（例如 `DSC01234.ARW` $\rightarrow$ `DSC01234.xmp`）。
- **無縫跨軟體協同**：LumiBase 寫入的 `.xmp` 可在 **Adobe Lightroom Classic**、**Adobe Bridge**、**Camera RAW** 與 **Capture One** 中直接讀取，完整保留評分與修圖參數。

## 8. 高品質 JPEG 批次匯出 (Export Workflow)

- **快捷匯出 (`⇧⌘E`)**：選取欲匯出的相片（未選取時預設匯出全部），按下 **`⇧⌘E`** (Shift + Command + E) 或點擊工具列上的 **「Export」** 按鈕。
- **高畫質算圖**：全尺寸感光元件 Demosaicing 算圖，並完整套用色調曲線、裁切旋轉與降噪銳化。
- **完整 EXIF 保存**：相機型號、鏡頭資訊、ISO、快門、光圈、焦距、拍攝日期與 GPS 定位均完整保留。
- **標準 sRGB 色彩空間**：自動標記與轉換色彩設定檔，確保在各家手機、平板與社群平台上色彩皆鮮明一致。
- **即時進度浮動 HUD**：右下角顯示即時處理相片名稱與進度條，隨時可按 Cancel 中止。
