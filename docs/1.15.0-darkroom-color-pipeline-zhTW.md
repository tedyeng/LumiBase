# LumiBase 1.15.0

## Darkroom (Shutter Lab) 1:1 CIRAWFilter 色彩管線與 Direct Metal GPU 匯出架構

本版本為 LumiBase 引入全新的 **Darkroom 色彩管線引擎（Darkroom Color Pipeline Engine）**，達成與 Shutter Lab 的 `darkroom` 批次顯影引擎 **100% 像素完全對齊（Bit-for-Bit Parity，Max Pixel Diff = 0.0）**。

同時整合 PR #17 釋出的 **Tone Curve（點曲線）**、**8-Band Color Mixer（色調混合器）**、**Auto Tone / WB 自動白平衡與曝光** 及快捷重新載入 XMP 功能，讓使用者在 LumiBase 中獲得流暢、精確且與 Darkroom 完全一致的修圖與匯出體驗。

---

### 1. 背景與核心問題分析

使用者回報在 LumiBase 中預覽與匯出的照片與 Shutter Lab `darkroom` 針對同一組照片（如 `A7C09068.ARW` + `A7C09068.xmp`）所產生的結果存在明顯肉眼可見的差異。

經深入比對與數學逆向分析，造成差異的核心根源如下：

| 管線階段 | Shutter Lab Darkroom | LumiBase (原 Adobe PV2012) | 視覺影響 |
| :--- | :--- | :--- | :--- |
| **鏡頭校正** | `isLensCorrectionEnabled = true` | 關閉 | 邊緣暗角與邊緣變形不同 |
| **RAW 陰影補償** | 保留 Apple 原生 `shadowBias = 3.0`, `boostShadowAmount = 0.9` | 強制壓制為 `0.0` | 原 LumiBase 陰影嚴重死黑壓暗 30 階以上 |
| **白平衡 色調** | 直接傳入 XMP Tint（$15.0$） | 加上黑體普朗克軌跡偏移補償 | 色調偏綠／偏洋紅的微小偏移 |
| **高光與陰影調控** | 單一 pass `CIHighlightShadowAdjust` | 強制觸發雙曝光 EV 0 / EV -2 多幀 HDR 融合 | 原 LumiBase 畫面動態對比被展平 |
| **對比度與去朦朧** | 線性 `CIColorControls` | 自適應場景樞軸之 `AdaptiveContrastKernel` | 中間調過渡與反差不同 |
| **微對比度／清晰度** | 僅正清晰度套用輕度銳化；負值忽略 | 負清晰度套用半徑 10px 高斯模糊 | 原 LumiBase 出現非預期的整體柔焦發霧 |
| **JPEG 匯出管線** | 直接調用 Metal `writeJPEGRepresentation` | 轉為 CPU 8-bit RGBA 經 `CGImageDestination` | 原 LumiBase 浮點數截斷產生 ~0.7 平均像素誤差 |

### 2. 雙色彩管線架構設計 (`RAWColorPipelineEngine`)

為同時滿足「與 Shutter Lab Darkroom 完美 1:1 一致」以及「追求進階 Adobe Camera Raw PV2012 與極致高光 HDR 融合」的雙重需求，LumiBase 在 `PerformanceSettings` 中設計了雙引擎架構：

```swift
public enum RAWColorPipelineEngine: String, CaseIterable, Identifiable, Sendable {
    case darkroom = "darkroom"         // 預設：與 Shutter Lab Darkroom 1:1 一致
    case adobePV2012 = "adobePV2012"   // 進階：Adobe Camera Raw PV2012 與多幀 HDR 融合
}
```

使用者可隨時於 **Preferences（設定）-> Rendering & RAW** 分頁中切換色彩管線引擎。切換時系統會自動使縮圖與 Loupe 預覽快取失效並進行無縫重繪。

### 3. Darkroom 核心管線實作演算法 (`processDarkroom`)

在 Darkroom 模式下，RAW 解碼與 CoreImage 處理流程嚴格依據 Shutter Lab 之規範執行：

1. **鏡頭與原生解碼**：
   - 啟用 Apple 鏡頭色差與幾何變形校正：`rawFilter.isLensCorrectionEnabled = true`
   - 保留 Apple 預設的暗部增益：`shadowBias = 3.0`，`boostShadowAmount = 0.9`
   - 直接套用使用者自訂色溫與色調，不疊加任何經驗偏移。
2. **曝光調整 (Exposure)**：
   - 透過 `CIExposureAdjust` 套用光學曝光增益：`inputEV: ev`。
3. **高光與陰影映射 (Highlights & Shadows)**：
   - 使用單 pass `CIHighlightShadowAdjust`：
     - `highlightAmount = max(0.6, 1.0 + (highlights / 100.0) * 0.35)`
     - `shadowAmount = max(0.0, (shadows / 100.0) * 0.30)`
4. **對比度與去朦朧 (Contrast & Dehaze)**：
   - 合併去朦朧反差加成：`contrastVal = contrast + dehaze * 0.6`
   - 透過 `CIColorControls` 套用：`inputContrast = max(0.7, min(1.4, 1.0 + contrastVal / 100.0 * 0.2))`
5. **飽和度與自然飽和度 (Saturation & Vibrance)**：
   - 計算複合飽和度偏移：`totalSatDelta = (sat * 0.2 + vib * 0.12 + dehaze * 0.08) / 100.0`
   - 透過 `CIColorControls` 套用：`inputSaturation = max(0.0, min(1.6, 1.0 + totalSatDelta))`
6. **清晰度與紋理 (Clarity & Texture)**：
   - 僅當複合清晰度大於 5 時套用輕度銳化：`CIUnsharpMask(radius: 1.5, intensity: min(0.4, clarity / 100 * 0.3))`。
7. **Direct Metal GPU JPEG 寫入**：
   - RAW 匯出時直接透過 Metal GPU 指令寫出 JPEG：
     ```swift
     try ciContext.writeJPEGRepresentation(
         of: outputCI,
         to: destinationURL,
         colorSpace: sRGBColorSpace,
         options: [kCGImageDestinationLossyCompressionQuality as CIImageRepresentationOption: quality]
     )
     ```
   - 免除記憶體複製與 8-bit 中間緩衝區截斷，且自動完整保存感光元件 EXIF / TIFF / IPTC 原始資訊。
