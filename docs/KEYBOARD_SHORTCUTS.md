## 1. 工作區與檢視模式 (Workspace & Views)

| 快捷鍵 | 功能名稱 | 詳細用途說明 |
| :---: | :--- | :--- |
| **`G`** | **Library（圖庫網格）** | 切換至圖庫工作區，並開啟多張相片網格總覽（Grid View）。 |
| **`D`** | **Develop（顯影修圖）** | 直接切換至顯影修圖工作區，並自動將相片切入大圖檢視以利微調。 |
| **`E`** | **Loupe View（大圖檢視）** | 將當前選取的相片放大為單張預覽檢視（120fps 硬體加速顯示）。 |
| **`Space`**<br>(空白鍵) | **Grid / Loupe 快速切換** | 在「網格總覽」與「單張大圖」之間即時來回切換。 |
| **`Enter`** / **`Return`** | **進入大圖** | 在網格檢視選取相片後，按 Enter 進入單張大圖。 |
| **`Esc`** | **返回 / 取消** | 大圖下返回網格總覽；裁切模式下放棄變更；搜尋時清除輸入焦點。 |
| **`Z`** | **1:1 原生畫素切換** | 在大圖檢視中，於「全圖適配 (Fit)」與「100% 原始畫素」間切換。 |
| **`I`** | **資訊抬頭顯示 (HUD)** | 開啟或關閉左上角懸浮顯示的 EXIF 與銳利度分析中繼資料。 |
| **`Tab`** | **隱藏 / 展開兩側面板** | 一鍵同時收合或展開左側目錄樹與右側檢查器，最大化工作視野。 |

## 2. 相片瀏覽與選取 (Navigation & Selection)

| 快捷鍵 | 功能名稱 | 詳細用途說明 |
| :---: | :--- | :--- |
| **`←`** | **上一張相片** | 選取並顯示前一張相片。 |
| **`→`** | **下一張相片** | 選取並顯示後一張相片。 |
| **`↑`** | **網格往上一行** | 在 Grid 網格中依欄數向上跳轉一行。 |
| **`↓`** | **網格往下一行** | 在 Grid 網格中依欄數向下跳轉一行。 |
| **`⌘A`** | **全選 (Select All)** | 全選目前篩選條件下的所有相片。 |
| **`⌘D`** | **取消全選 (Deselect All)** | 取消所有已選取的相片。 |
| **`⌘ + 點擊`** | **個別加選 / 減選** | 點選個別相片進行非連續的多選。 |
| **`Shift + 點擊`** | **範圍連續選取** | 選取從上一次選取點到當前相片之間的所有相片。 |
| **`⌘⌫`** 或 **`Delete`** | **移至垃圾桶 (Move to Trash)** | 將選取的相片及其 XMP 側錄檔移入系統垃圾桶（具防誤刪確認）。 |
| **`⌘F`** | **聚焦搜尋框** | 將輸入游標聚焦至頂部搜尋列，可依檔名、相機或關鍵字搜尋。 |

## 3. 星等評選與旗標標記 (Rating & Flagging)

| 快捷鍵 | 功能名稱 | 詳細用途說明 |
| :---: | :--- | :--- |
| **`0`** | **清除評分** | 將目前相片的星等設為 0 星（清除）。 |
| **`1` ~ `5`** | **1 ~ 5 星評分** | 直接將相片評等設為對應的星數（1★ ~ 5★）。 |
| **`]`** | **評分 +1 星** | 將目前評分增加一星（上限 5 星）。 |
| **`[`** | **評分 -1 星** | 將目前評分減少一星（下限 0 星）。 |
| **`P`** | **留用旗標 (Pick Flag)** | 標記為精選相片（白色旗標，便於後續批次篩選留用）。 |
| **`X`** | **剔除旗標 (Reject Flag)** | 標記為廢片（紅色打叉，便於一鍵過濾並批次清除）。 |
| **`U`** | **取消旗標 (Unflagged)** | 清除留用或剔除標記，恢復為無旗標狀態。 |

## 4. 顯影工具與即時對比 (Develop & Comparison)

| 快捷鍵 | 功能名稱 | 詳細用途說明 |
| :---: | :--- | :--- |
| **`\`** | **Before / After 快速對比** | 按下時瞬間在「原始拍攝圖（As Shot）」與「調色後效果」間切換。 |
| **`Y`** | **循環對比模式 (前進)** | 循環切換：單圖 $\rightarrow$ 左右分割線 $\rightarrow$ 雙圖並排 (2-Up) $\rightarrow$ 上下分割 $\rightarrow$ 關閉。 |
| **`⇧Y`** | **循環對比模式 (後退)** | 逆向循環切換上述各項分割對比模式。 |
| **`E`** (Develop下) | **編輯調整工具** | 聚焦於 Basic 調色面板與曲線調整。 |

## 5. 裁切與水平校正 (Crop & Straighten)

| 快捷鍵 | 功能名稱 | 詳細用途說明 |
| :---: | :--- | :--- |
| **`R`** | **開啟 / 關閉裁切模式** | 進入或退出相片裁切與水平傾斜角度校正工具。 |
| **`O`** | **循環輔助導引線** | 在多格水平參考網格（Grid）與三分法則構圖線（Rule of Thirds）間切換。 |
| **`X`** (裁切中) | **翻轉裁切方向** | 快速將裁切框在直向與橫向構圖之間旋轉翻轉。 |
| **`Enter`** / **`Return`** | **確認裁切** | 儲存裁切設定至 XMP 並關閉裁切模式。 |
| **`Esc`** | **取消裁切** | 放棄當次調整並退出裁切工具。 |

## 6. 批次同步與參數複製貼上 (Sync & Copy/Paste)

| 快捷鍵 | 功能名稱 | 詳細用途說明 |
| :---: | :--- | :--- |
| **`⇧⌘C`** | **複製顯影設定 (Copy)** | 彈出選擇性設定對話框，挑選要複製的色彩／白平衡／裁切參數。 |
| **`⇧⌘V`** 或 **`⌥⌘V`** | **貼上顯影設定 (Paste)** | 將剪貼簿中的顯影設定直接批次套用至目前選取的所有相片。 |
| **`⇧⌘S`** | **同步顯影設定 (Sync)** | 多選相片時開啟同步面板，將主相片參數批次覆蓋到其他選取相片。 |
| **`⌥⇧⌘S`** 或 **`⌥⌘S`** | **開關自動同步 (Auto Sync)** | 啟用後，在多選狀態下調整任何滑桿，所有選取相片將即時同步聯動。 |

## 7. 檔案管理與系統操作 (File & System)

| 快捷鍵 | 功能名稱 | 詳細用途說明 |
| :---: | :--- | :--- |
| **`⌘O`** | **開啟資料夾 (Open Folder)** | 呼叫 macOS 原生目錄選擇器以載入相片資料夾。 |
| **`⇧⌘E`** | **批次匯出 (Export Photos)** | 將選取（或過濾清單中）的相片批次算圖匯出為全解析度高品質 JPEG。 |
| **`⇧⌘R`** | **強制重讀 XMP (Reload XMP)** | 手動強制自磁碟重新讀取 `.xmp` 側錄檔（本機一般情況下系統會自動監聽並載入）。 |
| **`⌘,`** | **偏好設定 (Settings)** | 開啟 LumiBase 效能、快取與邊緣畫質設定面板。 |

## 8. 滑鼠與觸控板快捷手勢 (Gestures & Mouse)

| 操作方式 | 功能名稱 | 詳細用途說明 |
| :--- | :--- | :--- |
| **滑鼠左鍵雙擊相片** | **100% 畫素檢視** | 於點擊位置為中心切換 100% 原生畫素顯示與全圖 Fit 適配。 |
| **100% 下滑鼠拖曳** | **畫素平移 (Pan)** | 即時游移檢視相片各部位的對焦與毛孔細節。 |
| **雙擊分割對比中線手柄** | **分割線置中** | 在 Before/After 左右分割模式下，將分割線快速還原回 50% 居中位置。 |
| **雙擊數值滑桿標籤 / 數值** | **數值快速復位** | 將單項調色滑桿（如 Exposure、Temp、Shadows 等）直接歸零重設。 |
| **雙指橫向滑動 / 滾輪** | **底片列平滑捲動** | 在底部底片縮圖列（Filmstrip）進行高影格率平滑水平捲動。 |

---

> 💡 **提示**：將滑鼠游標懸停在介面上的按鈕或控制項上約 1 秒，會顯示原生的 Tooltip 浮動提示，當中亦包含該功能的鍵盤快捷鍵。
