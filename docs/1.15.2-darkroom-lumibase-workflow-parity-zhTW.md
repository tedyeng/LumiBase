# Darkroom & LumiBase 工作流與預覽/匯出一致性改進計畫

## 背景與目標
使用者工作流程為：
1. 使用 `shutter-lab` 的 `photofilter` 進行連拍分組挑選照片（打上評星與選片旗標）。
2. 使用 `darkroom` 進行風格預測與 RAW 顯影處理，產出 `.xmp`。
3. 使用 `LumiBase` 查看後製結果、微調。
4. 最終匯出 JPEG。

目標：
- 保證 `photofilter` 的挑片中繼資料（`Rating`、`Pick` / `PickedStatus`、`Label`）在 `darkroom` 批次後製時被完整繼承，且可自動過濾被淘汰的廢片。
- 保證 `darkroom` 產出的 XMP 在 `LumiBase` Preview（縮圖、Fit、100% 放大）與兩者各自匯出 JPG 時的色彩、反差、曲線、黑白及旋轉裁切 1:1 完全一致。

---

## 關鍵問題診斷與修復計畫

### 模組 1：`shutter-lab` (`photofilter` + `darkroom`)
1. **XMP 標籤保留與相容性** (`src/darkroom/xmp_parser.py`, `src/darkroom/photo_filter.py`)
   - 在 `DevelopSettings` 加入 `rating: int = 0`、`pick_status: int = 0`、`color_label: str = ""`。
   - `XMPParser.parse_string` 讀取既有 XMP 的 `xmp:Rating`、`crs:Pick`、`crs:PickedStatus`、`xmp:Label`。
   - `XMPParser.to_xmp_string` 序列化時寫回上述標記，避免後製時被沖刷覆蓋。
   - `photo_filter.py` 寫入時同時補上 `crs:Pick` 與 `crs:PickedStatus`，雙向相容 Lightroom 與 LumiBase。

2. **批次處理支援跳過淘汰照** (`src/darkroom/batch_processor.py`)
   - `BatchJob` 與 `BatchProcessor.run` 加入 `--skip-rejected` 參數（預設支援判斷若同目錄存在 `.xmp` 且 `pick_status == -1` 或 `rating == 1` 時略過）。

3. **CoreImage 匯出補齊黑白與自訂曲線** (`src/darkroom/coreimage_decoder.py`)
   - 在 `export_lumibase_pipeline` 加入黑白模式（`convertToGrayscale` 或 `saturation == -100` 套用 `CIPhotoEffectMono`）。
   - 加入 `ToneCurvePV2012` 曲線支援，透過 Metal Kernel / Spline 9 控制點映射 RGB/R/G/B 色調曲線。

4. **修復 `render_and_save` 在 CoreImage 下跳過自動曝光/水平旋轉計算的問題** (`src/darkroom/raw_processor.py`)
   - 在呼叫 `CoreImageDecoder.export_lumibase_pipeline` 之前，先完成 `auto_exposure` 與 `auto_straighten` 計算，並計算出最大內接裁切框填入 `crop_top/bottom/left/right`，確保 XMP 記錄的參數與渲染結果完全對齊。

---

### 模組 2：`LumiBase`
1. **旋轉去黑邊裁切演算法對齊** (`LumiBase/Services/Image/AdobeColorPipeline.swift`)
   - `applyCrop`: 當 `abs(angleDeg) > 0.01` 且無手動自訂裁切邊界時，自動計算最大內接矩形（Largest Inner Bounding Box）進行裁切，與 `darkroom` 1:1 對齊，避免畫面留下四角黑邊。

2. **XMP 解析相容 `crs:PickedStatus`** (`LumiBase/Services/Metadata/XMPParser.swift`)
   - 在屬性字典解析與正則表達式 fallback 中，支援 `pickedstatus`，無縫辨認 `photofilter` 的選片標記。

3. **縮圖管線與預覽一致性** (`LumiBase/Services/Image/ThumbnailLoader.swift`, `LumiBase/Services/Image/AdobeColorPipeline.swift`)
   - 確保 `createThumbnail` 套用 Darkroom 管線時色彩一致。
   - `processDarkroom` 在縮放預覽時（Fit 模式 proxy），清晰度（Clarity）與紋理（Texture）半徑依據 proxy 比例適度調配，避免小圖過度銳化/柔焦。

---

## 驗證流程
1. 在 `LumiBase` 執行 `swift test` 驗證所有單元測試通過。
2. 在 `shutter-lab` 執行 `pytest` 驗證 XMP roundtrip、CoreImage decoder 及 photo filter 測試通過。
3. 建立端到端驗證案例（產生帶有評星、旋轉角度、色調曲線的 XMP，驗證 LumiBase 與 Darkroom 輸出像素與中繼資料一致性）。
